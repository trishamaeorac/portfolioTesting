Portfolio Website

This repository contains my personal portfolio website showcasing my profile, projects, and contact. The website is built using HTML, CSS, and JavaScript, with additional use of Django for backend.

Table of Contents
Project Overview
Technologies Used
Features

Project Overview
This portfolio website highlights the following:

Personal Introduction: A section with a profile image and introduction about me, including my background and skills.

Projects: Showcases the projects I’ve worked on, such as the "Coke Sales and Inventory System,"and "Game Web App - Deal or No Deal" together with their descriptions.

Contact Form: A simple form where users can reach out to me via email. After form submission, an alert message appears.
Animations: Smooth transitions and animations when navigating through the website, including image galleries and toggleable project content.



Technologies Used

Frontend: HTML, CSS, JavaScript
Backend: Django (if used)

Other:
Static file management using Django {% static %} tag


Features

Responsive Layout: The portfolio adapts to various screen sizes for both desktop and mobile views.

Interactive Projects: Project sections that expand with more details and include image galleries with navigation buttons to cycle through images.

Smooth Animations: All sections (Profile, Projects, and Contact) have smooth transitions to enhance the user experience.

Contact Form: Allows users to send messages through the form, with a success message displayed upon submission.


Installation

To run this project locally, follow these steps:

Clone the repository:

git clone -b Portfolio https://github.com/trishamaeorac/Portfolio.git



Navigate to the project directory:

cd portfolio

Install dependencies (if using Django, set up the virtual environment and install required packages):
pip install Django

Run the server:
python manage.py runserver

Open your browser and go to http://127.0.0.1:8000/ to view the site.
